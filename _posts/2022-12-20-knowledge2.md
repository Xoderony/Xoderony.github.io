# 关于指针运算

## ·指针运算不改变指针类型

如：

```text
int arr[3] = { 1,2,3 };
&arr + 1;  //&arr表示整个数组的地址，+1跳过这个数组，虽然越界了，但是其类型仍然为 int (*) [3];

```

这时就有 sizeof(*(&arr + 1)) = 12; 这时 sizeof 计算的其实是 int [3] 这个类型的大小
