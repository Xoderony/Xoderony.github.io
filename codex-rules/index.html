从这里，到你的 Codex
在浏览器里定制
规则逐条选择，Skills 按完整技能选择。草稿只留在当前浏览器，刷新或下次打开可继续；换设备不会同步。清除浏览器数据会删除草稿。
把材料交给 Agent
复制的提示词含有你的修改和技能附带文件。内容较长时，下载完整安装材料并交给 Codex，避免聊天输入被截断。
确认每一处变化
Agent 先检查目标电脑的目录和已有规则，解释重复、相似、可合并及冲突项。你可以逐项决定，或接受全部已展示的建议。
这里提供的是个人规则快照，适用范围由你选择。Skills 内原有授权语句也属于待审阅内容，不代表访客已经授权。快照可能包含来源电脑的绝对路径；安装前请检查并按目标环境调整。仅相对路径形式的跨技能引用会自动包含依赖，其余依赖请在安装时核查。发布新版本不会自动改变你的本机配置。
