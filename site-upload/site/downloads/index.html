如何与好友联机

和好友进入同一个大厅

  1. 每个人安装当前版本，打开 Steam 并登录。
  2. 在主菜单选择相同玩法，点击“进入玩法”。
  3. 一人创建大厅，把大厅 ID 发给好友。
  4. 其他人在同一玩法内输入大厅 ID 加入；请勿跨玩法加入大厅。

之后可使用桌面快捷方式，或运行安装目录内的 Start-Expriverse.cmd。测试结束直接退出游戏，安装目录会保留。

需要 Windows 10 / 11 x64、已登录的 Steam，以及 Microsoft Visual C++ x64 Redistributable（已安装可跳过；微软官方下载）。每位玩家使用各自的 Steam 账号。

已有游戏？查看更新与移除说明

已有游戏，如何更新？

退出游戏，双击游戏目录内的 Update-Expriverse.cmd。它会显示最新版本，确认后完整下载并校验，再替换当前游戏；桌面快捷方式保持不变。已是最新版本时无需下载。

设置与日志会保留，缓存重新生成。更新失败时恢复旧版；若断电或文件占用导致恢复失败，安装器会显示保留旧版的位置。首次安装请使用上方入口；旧版独立版本目录不迁移。

需要移除时，先退出游戏，再删除安装目录和自行创建的快捷方式。

03 / TECHNOLOGY

引擎与框架，各司其职

从引擎能力到通用模块，再到 Expriverse 自身的玩法与联机实现。

游戏引擎

Stride

提供场景与实体组件、渲染、资源构建、音频及 UI 等游戏引擎能力，承载各个玩法场景。

语言与运行时

C# / .NET 10

承载游戏逻辑与基础模块。当前 Windows 发布包包含 .NET 运行时，玩家无需单独安装。

物理模拟

BepuPhysics

通过 Stride 的 BepuPhysics 集成提供刚体、碰撞与物理模拟，支持弹球等物理交互。

通用基础框架

Xoderony

独立开发的基础模块集合，为项目提供依赖注入、本地化、集合、序列化等通用能力。

游戏自身的联机实现

Expriverse 网络模块

由游戏项目维护会话、网络通信及玩法同步相关机制，与 Xoderony 通用框架独立组织。

当前平台接入

Steamworks.NET

连接 Steam 原生接口，为当前版本的 Steam 大厅与网络接入提供基础。玩家需要启动并登录 Steam。

04 / CREATION · 设计目标

让创作者定义玩法

Expriverse 以场景组织独立玩法。模组的设计目标是让作者自主定义角色控制、相机、界面与游戏规则，并选择单人或联机方式，构建不同类型的游戏体验。

当前进度：仍在建设

模组创作暂未向外部开放，当前下载包用于体验内置玩法。上面的创作自由度属于设计目标，尚不代表已经提供完整的模组制作、加载或分发工具。
