临时测试安装

Expriverse · 2026-10-02 fix3 · Windows x64

安装、运行，测试后清理

  1. 先打开 Steam，登录自己的账号。
  2. 在 Windows PowerShell 或 PowerShell 中粘贴下面的命令。
  3. 输入 Yes：下载到桌面上的独立测试目录，校验后解压并运行。输入 No 则取消，不创建安装文件。
  4. 保持终端窗口打开，完成游戏测试。
  5. 需要反馈的日志先另行保存。测试结束后回到终端，输入 Delete：结束本次启动的游戏进程树，并删除安装目录、日志和下载文件。
查看脚本

请用 Delete 完成清理，不要直接关闭终端或关机。强制关闭时无法保证文件清理完成。脚本只管理自己的测试目录和进程，不删除 Windows、Steam 自身产生的缓存或记录。
